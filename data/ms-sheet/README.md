# Middle school results sheet

`Heights MS XC Results.xlsx` is a copy of the team's Google Sheet **Heights MS XC Results**. The website's middle school
races (the sheet tabs) are built from it.

- If the Google Sheet is shared as **Anyone with the link → Viewer**, the website downloads a fresh copy **every morning** by itself
  (only when something in the sheet actually changed).
- Otherwise: in Google Sheets click **File → Download → Microsoft Excel (.xlsx)**, then here click **Add file → Upload files**,
  drop the file in and click **Commit changes**. Keep the name `Heights MS XC Results.xlsx` so it replaces this copy.

See [HOW-TO-UPDATE.md](../../HOW-TO-UPDATE.md).
