# Race results added by hand

Put **one CSV file per race** in this folder (**Add file → Upload files**). The website adds it by itself within a few minutes.
Full step-by-step instructions: **[HOW-TO-UPDATE.md](../HOW-TO-UPDATE.md)**.

- Start from **`_TEMPLATE.csv`** (blank). **`_EXAMPLE.csv`** shows a filled-in race. Files whose name starts with `_` are ignored.
- The top rows say what the race was: **Meet, Date, Venue, Level** (MS or HS), **Race** (Varsity / JV / Freshman / Open), **Distance**, **Source** (a link, optional), **Notes** (optional).
- Then one header row, **Place, Name, Grade, School, Time**, and one row per runner.
- Our school is **The Heights** (or leave School empty for our runners). Include the other schools' runners too if you have them, so the site can work out team scores.
- Times like `17:42.3`. **DNF** with no place for a runner who didn't finish.
- If a file has a mistake, it's left out (the rest of the site still updates). The **Actions** tab shows which row to fix.
